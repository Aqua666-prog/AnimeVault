# AnimeVault 0.3.0

## Главное

- общий онлайн-каталог с переключением AniLiberty, AnimeLib, AnimeVost,
  YummyAnime, AnimeGo, Jut.su и Anixart;
- обложки и метаданные каждого источника;
- HLS/MP4 через Media3, защищённые iframe через WebView;
- выбор качества, озвучки и плеера;
- раздельный прогресс по источникам и миграция прогресса AniLiberty 0.2.0;
- защищённые сессии AnimeLib/Anixart через Android Keystore;
- отдельный вход Anixart и ручной токен AnimeLib в настройках.

## Совместимость

- Android 8.0 (API 26) и новее;
- схема локальной Room-базы не менялась;
- устанавливается поверх 0.1.x и 0.2.x без удаления папок и локального прогресса.

## Известные ограничения

- AnimeGo и Jut.su зависят от HTML-разметки и отмечены как beta;
- у Jut.su поиск выполняется по ссылке или slug;
- iframe-плееры не отдают точную позицию просмотра приложению;
- Anixart использует нестабильный непубличный API и требует отдельный аккаунт.

# Дизайн-система AnimeVault

Темы остаются владельцами палитры, типографики, формы и семантических цветов.
Raiden Shogun Edition сохраняет орнамент, аметистовые поверхности и золотые
маркеры. Общая карточка постера использует `VaultSpacing`, форму темы,
`VaultArtwork`, текстовые подписи и один интерактивный элемент. Обложка в
карточке декоративна, TalkBack получает название и метаданные из текста.

| Пресет | Поведение |
| --- | --- |
| Performance | Минимальная длительность движения, без декора, размытия, теней Vault-панелей и выборки цветов |
| Balanced | Базовые переходы, умеренная тень, 10 dp Haze с входом 0,5×, динамический цвет по настройке |
| Cinematic Ultra | 20 dp Haze с входом 0,67×, динамический оттенок, дополнительная глубина, parallax при полном движении и фирменная заставка |

Эффективный пресет меняется сразу после записи в DataStore. Battery Saver
временно применяет Performance. На API 24–30 и low-RAM панель текста использует
тональную заливку. Системное отключение анимаций и пользовательский reduced
motion соблюдаются. Cinematic Ultra показывает интерактивно пропускаемую
заставку при первом запуске процесса.

Haze получает слой только от баннера Home и карточки тайтла. Панели навигации,
плеера, меню и диалогов используют контрастные тональные поверхности.
Размытие видео через SurfaceView требует другого пути композиции и проверки
на GPU, поэтому предпринят только самый небольшой полезный захват.

Календарь использует VaultFilterChip, статический skeleton и панель ошибки с
повтором. Общее состояние прогресса читается в фазе отрисовки. Избранное и
загрузка меняют доступный текст или значок одновременно с коротким
переходом цвета. Выбор пресета имеет состояние radio button для TalkBack.
В больших окнах используются существующие адаптивные сетки и боковая навигация.

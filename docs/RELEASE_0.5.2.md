# AnimeVault 0.5.2

Исправление контрастности после визуального обновления 0.5.1.

## Что исправлено

- названия аниме в онлайн-каталоге теперь всегда белые;
- название и полное описание релиза теперь всегда белые;
- заголовки «Озвучка и субтитры» и «Серии» больше не наследуют чёрный цвет;
- названия локальных тайтлов также явно окрашены в белый;
- корневой `LocalContentColor` закреплён как белый, чтобы новые экраны и
  состояния по умолчанию не повторяли эту ошибку;
- версия повышена до `0.5.2` (`versionCode 10`).

Плеер, источники и схема Room не изменялись. APK подписан прежним ключом и
устанавливается поверх 0.3.1–0.5.1 с сохранением данных.

# AnimeVault 0.7.3

Версия 0.7.3 расширяет онлайн-часть от набора разрозненных вкладок до первого
варианта мульти-источникового каталога.

## Новые источники

- **Dream Cast** — поиск релизов и извлечение HLS из конфигурации Playerjs.
- **AniMedia** — DLE-поиск, список серий и ленивое извлечение HLS из VOD.
- **AnimeON** — публичные API поиска, переводов и серий; используются только
  публично доступные ответы сервиса.
- **SameBand** — новинки/поиск и прямой плейлист 480p/720p/1080p.
- **AnimeBest** — поиск и `videoList` с несколькими озвучками; iframe
  разрешается в HLS только при запуске серии.

С учётом прежних AniLiberty, Kodik, AnimeLib, AnimeVost и Jut.su приложение
имеет 10 прямых провайдеров.

## «Все источники»

Добавлен `UnifiedOnlineProvider`. Он:

1. параллельно запрашивает подходящие источники;
2. объединяет совпадающие карточки;
3. кодирует в ID объединённой карточки ссылки на исходные релизы, поэтому она
   восстанавливается после перезапуска процесса;
4. при открытии тайтла объединяет серии;
5. при старте воспроизведения передаёт каждую исходную серию обратно её
   провайдеру, поэтому сохраняются ленивые резолверы Kodik, AnimeLib,
   AniMedia и AnimeBest;
6. удаляет дубликаты потоков и подписывает источник каждого варианта.

`OnlineTitleMatcher` прежде всего использует Shikimori/MAL/AniList ID, когда
они доступны. При сравнении названий отдельно проверяются номер сезона и part,
чтобы `Season 2` не слипался с `Season 3` после нормализации текста.

## Совместимость

- `versionCode`: 15
- `versionName`: 0.7.3
- версия Room остаётся 2, новая миграция БД не требуется;
- сохранённые настройки и прогресс прежних источников не меняются.

## Проверка

Для новых парсеров добавлены unit-тесты на зафиксированных HTML/JSON-фрагментах.
В среде подготовки релиза дополнительно выполнена компиляция доменного слоя и
новых провайдеров через локальный `kotlinc`; HTTP/Gson Android-зависимости в
этой проверке заменены сигнатурными stubs.

Полный `Gradle testDebugUnitTest` здесь не был выполнен: дистрибутив Gradle 9.5
не находится в локальном кэше, а среда не может скачать его с
`services.gradle.org`. Перед APK-релизом проект нужно один раз собрать в Android
Studio или среде с доступным Gradle wrapper.

## Известные ограничения

- AnimeON и AnimeBest пока search-first: пустой запрос не строит полную ленту.
- SameBand начинает поиск с четырёх символов.
- единая пагинация приблизительна, потому что исходные каталоги имеют разные
  сортировки и размеры страниц;
- HTML-адаптеры по природе требуют сопровождения при изменении разметки сайтов;
- приложение не обходит геоблокировки, Premium/account gates или DRM.

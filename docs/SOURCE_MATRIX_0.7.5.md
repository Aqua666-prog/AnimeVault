## Поведение плеера 0.7.5

Для каждого онлайн-релиза продолжают храниться предпочитаемая озвучка и качество. Если выбранный нативный URL не запускается, плеер теперь может автоматически перейти к следующему потоку. Сначала ищется та же озвучка, затем нативный HLS/MP4, затем наиболее высокое доступное качество. Embed остаётся последним резервом.

Health-check предназначен для быстрой диагностики каталожного API/страницы. Он не гарантирует, что каждая конкретная серия и каждый CDN-поток воспроизводятся в данный момент.

## Что исследовать дальше

- более строгий ID mapping через Shikimori/MAL/AniList для уменьшения ложных объединений;
- фоновая статистика деградации источников без агрессивных периодических запросов;
- перенос краткоживущего каталожного кэша на дисковый слой после стабилизации модели;
- нативное извлечение HLS из тех embed-плееров, где это возможно без хрупкого WebView scraping.

## Исследовано, но пока не подключено

### Studio Band / studio-band.ru

Текущие карточки сайта одновременно перечисляют AniDUB, Anilibria, Анимевост и
Студийную Банду. Это делает ресурс интересным именно как индекс нескольких
русских озвучек. В 0.7.3 адаптер не добавлен: до интеграции нужно закрепить
стабильный публичный контракт плеера/серий, а не привязываться вслепую к
результатам поискового индекса.

### YummyAnime / api.yani.tv

Найден публичный API для поиска, карточек и `/anime/{id}/videos`. Ответы видео
содержат `data.dubbing`, `number` и `iframe_url`, то есть ресурс полезен как
индекс `тайтл → серия → озвучка`. Часть плееров требует отдельного резолвера,
поэтому его разумно подключать следующим этапом, после выделения общего
`EmbedResolver`.

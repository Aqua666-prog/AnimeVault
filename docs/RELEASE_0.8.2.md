# AnimeVault 0.8.2 — Obsidian

Obsidian — второй проход по интерфейсу после Nocturne. Здесь меньше декоративного шума и больше «дорогой» продуктовой полировки: спокойная иерархия, единые состояния загрузки/ошибки, современная работа с выборами и несколько UX-улучшений плеера.

## Интерфейс

- новый Obsidian-проход по glass surfaces: более тонкие границы, тише фон, дополнительная мягкая виньетка;
- `VaultSearchField` переведён на outlined-композицию без старого Material underline;
- основные media cards получили короткую press-анимацию без пружин и избыточного масштаба;
- `WatchProgressBar` теперь анимирует изменение прогресса;
- общий `VaultEmptyState` используется для пустых и ошибочных экранов;
- общий `VaultSkeletonBlock` используется для skeleton-loading состояний;
- hero-карточки локального и онлайн-тайтла получают очень слабый backdrop из собственной обложки, поверх которого остаётся читаемая gradient-защита текста.

## Каталог и медиатека

- загрузка онлайн-каталога больше не выглядит как пустой экран с одним spinner: показывается сетка skeleton-постеров;
- загрузка страниц онлайн- и локального тайтла показывает skeleton hero + skeleton серий;
- сортировка локальной медиатеки открывается как Modal Bottom Sheet;
- жанры и сортировка онлайн-каталога также открываются как Modal Bottom Sheet вместо компактных DropdownMenu;
- после смены поиска, провайдера, фильтра или сортировки каталог возвращается к началу;
- локальная сетка возвращается к началу после поиска/сортировки;
- карточки медиатеки и онлайн-библиотеки получили тактильную press-motion анимацию.

## Плеер

- выбор скорости в локальном и онлайн-плеере переведён в единый bottom sheet;
- скорость по-прежнему хранится отдельно для каждого тайтла;
- онлайн-плеер теперь запоминает последний вручную выбранный профиль потока для тайтла:
  - озвучку/перевод;
  - качество;
  - физический источник;
- при переходе к следующей серии AnimeVault пытается выбрать максимально близкий поток; при отсутствии сохранённых предпочтений сохраняется прежнее поведение и берётся первый вариант источника;
- предпочтение не мешает существующему auto-failover: аварийное переключение по-прежнему ищет рабочий резервный поток и не перезаписывает осознанный выбор пользователя.

## Диагностика

- карточка диагностики показывает агрегированный результат проверки источников;
- во время проверки отображается общий progress indicator;
- после проверки видны счётчики доступных, упавших и требующих настройки провайдеров.

## Надёжность

- SAF, Room, сканирование папок, группировка сезонов, онлайн-провайдеры, прогресс, история, избранное, AnimeThemes, OP/ED skip и Media3 pipeline не переписывались;
- добавлен `OnlinePreferredStreamTest` для новой логики выбора потока;
- изменённые Kotlin-файлы проверены Kotlin PSI parser: синтаксических ошибок не обнаружено;
- полноценный Gradle build в текущей среде выполнить нельзя: wrapper запрашивает Gradle 9.5.0 с `services.gradle.org`, а сеть среды не даёт загрузить distribution.

# AnimeVault 0.7.7

0.7.7 добавляет музыкальные метаданные к онлайн-карточке, не связывая их с конкретным видеопровайдером и не усложняя Room.

## Музыка

После описания тайтла появляется блок «Музыка». Он показывает:

- OP/ED и порядковый номер;
- название композиции;
- исполнителя, когда он присутствует в записи источника;
- диапазон серий, если он указан в MyAnimeList;
- MAL ID и источник метаданных.

До трёх опенингов и трёх эндингов показываются сразу. Большие списки можно раскрыть полностью.

## Сопоставление тайтла

Порядок определения MyAnimeList ID:

1. точный `externalIds.malId` из подключённого провайдера;
2. `externalIds.shikimoriId` → `myanimelist_id` через публичный anime endpoint Shikimori;
3. fallback-поиск Jikan по английскому/основному названию, году и типу.

Fallback намеренно строгий: слабое похожее название не считается достаточным совпадением. Это важнее максимального покрытия, потому что неверный OP от соседнего сезона хуже отсутствующего блока.

## Надёжность

Музыкальные данные загружаются отдельной задачей после основной карточки. Ошибка Jikan или Shikimori не переводит релиз в error-state. Для metadata-блока есть собственная кнопка повтора.

Результаты кэшируются в памяти, Shikimori→MAL соответствия переиспользуются, а запросы Jikan сериализуются и разнесены небольшим интервалом, чтобы не создавать лишнюю нагрузку на публичный API.

## Тесты

Добавлены проверки:

- разбора строки `1: "Song" by Artist (eps 1-13)`;
- безопасного fallback для необычного текста темы;
- точного title/year match;
- отказа от слабого fuzzy match.

## Версия и данные

- `versionCode 19`, `versionName 0.7.7`;
- схема Room не менялась;
- миграция базы не требуется.

# AnimeVault 0.8.3 — Lumen

Lumen — третий проход по визуальной системе AnimeVault. Цель версии — сделать интерфейс менее «панельным» и более кинематографичным, не меняя рабочую механику медиатеки и источников.

## Визуальная система

- плавные fade/slide-переходы между экранами;
- новый cinematic poster aura в hero-карточках локальных и онлайн-тайтлов;
- стабильный per-poster chroma accent для карточек каталога, локальной и личной онлайн-медиатеки;
- фон без прежней технической сетки: мягкое диагональное световое поле и глубокая виньетка;
- editorial typography pass: спокойнее веса, аккуратнее tracking и вертикальный ритм;
- прогресс просмотра умеет принимать accent конкретного тайтла.

## Карточка тайтла

- обложка теперь формирует атмосферу hero-блока, а не просто дублируется слабым фоном;
- граница и status pill поддерживают индивидуальный accent тайтла;
- длинное описание онлайн-релиза сворачивается до шести строк и раскрывается плавно;
- существующие музыка AnimeThemes, жанры, озвучки и список серий сохранены.

## Плеер

- общий cinematic scrim для локального и онлайн-плеера;
- стеклянная единая chrome-кнопка для навигации и основных online actions;
- нижняя техническая строка заменена компактной двухуровневой панелью «сейчас играет»;
- в online player отдельно показываются тайтл, серия, выбранный поток и источник;
- в local player — тайтл, сезон/серия и имя файла;
- выбор качества/озвучки, сохранение предпочтений, skip OP/ED, equalizer, PiP и failover не менялись.

## Небольшие UX-правки

- «Моя медиатека» прокручивается к началу после смены вкладки;
- online library cards получили ту же accent-систему, что основной каталог;
- декоративная сложность уменьшена, но все action controls остаются доступными.

## Совместимость

- `versionCode 25`, `versionName 0.8.3`;
- Android 7.0+ / API 24+;
- миграции Room не требуются;
- схема данных не менялась;
- новые внешние зависимости не добавлялись.

## Проверки в среде сборки

- Kotlin PSI syntax check проходит для всего `app/src`;
- XML resources разбираются стандартным XML parser;
- полный `assembleDebug` в этой среде не выполняется, потому что Gradle Wrapper требует Gradle 9.5.0, а `services.gradle.org` недоступен по сети.

# Локальный ИИ MNN-Pocket

Продолжение Draft PR #58, ветка `feature/local-ai-mnn-pocket`. Это инженерная
сборка: реальный MNN, без облачной генерации и имитации ответов. Проверки и
ограничения текущего этапа описаны в [VALIDATION.md](VALIDATION.md).

## Установка и запуск

1. Нужны Android 7.0+ (API 24), ARM64 и 64-битный процесс. Предварительный порог
   допуска — 512 MiB свободной RAM; он не гарантирует отсутствие Android LMK.
2. Установите предоставленный debug APK с MNN. Для ADB:
   `adb install -r AnimeVault-local-ai-debug.apk`. Если установленный APK подписан
   другим ключом, сначала сохраните данные штатным экспортом; обновление поверх
   него Android не разрешит. Удаление приложения удаляет модель и переписку.
3. Главная → меню «Ещё» → «Локальный ИИ» → «Скачать модель».
   Около 175 МБ загрузки, минимум 210 МБ свободного места для новой установки.
   Файлы загружаются с официального Hugging Face, проверяются по размеру и
   SHA-256, затем устанавливаются в приватную папку `no_backup/local-ai/model`.
4. Либо скачайте комплект на компьютере:
   `python3 tools/local_ai/download_model.py /absolute/path/pocket-model`.
   Перенесите папку на устройство и выберите «Импортировать папку».
   Требуются все шесть файлов из закреплённого манифеста, включая `LICENSE.txt`.
   Другие экспорты и изменённые конфигурации намеренно отклоняются.
5. Отправьте сообщение. Первый запрос загружает модель в память; ответы поступают
   постепенно. «Остановить» прерывает генерацию кооперативно. Текущий native
   prefill/токен мгновенно прервать нельзя. «Очистить» удаляет историю.
6. Для подбора включите «Рекомендовать аниме». По умолчанию используются локальная
   библиотека и сохранённые онлайн-произведения. «Искать в онлайн-каталоге» включает
   сетевой поиск через существующий `OnlineRepository`: извлечённая моделью фраза
   отправляется выбранному провайдеру. Вся генерация остаётся на устройстве.
   Кнопки под ответом открывают существующие страницы произведений.

Загрузка/импорт выполняются, пока экран активен. Уход в фон останавливает работу
и выгружает модель из RAM. После отмены проверенные целые файлы сохраняются во
временной папке; незаконченный файл при повторе скачивается заново. HTTP Range
resume и фоновая загрузка пока не реализованы. Полоса прогресса относится к
переносу файлов; проверка хешей и загрузка в RAM могут занять дополнительное время.

Модель и история хранятся в `noBackupFilesDir`, не попадают в Android backup или
штатный экспорт библиотеки. История сохраняется атомарно в `chat-v1.json`, включая
частичный ответ при остановке. Один диалог, максимум 60 сообщений; при заполнении
очистите историю. Предел контекста — 2048 токенов, ответа — 256 токенов. История
обычного чата передаётся движку целиком; превышение контекста вызывает сообщение
об ошибке. Рекомендации используют отдельный контекст запроса и до 12 кандидатов.

## Модель и runtime

Официальный репозиторий: <https://huggingface.co/taobao-mnn/MNN-Pocket-0.3B-MNN>.
Ревизия: `cd0f6e9d7cad4351714e3919af5fc3bbdcf95dde`.
Лицензия Apache 2.0. Манифест: `app/src/main/assets/local-ai/manifest.json`.
В APK входят только манифест и код; веса отдельно. Импорт не выполняет произвольный
config: принимаются только точные байты проверенного официального комплекта.

MNN submodule: `b0239771b07b317a258fbc384683bbd540741406`, версия 3.6.2.
Сохранены `LocalAiEngine`, собственный JNI-мост, UTF-8 streaming, точная проверка
контекста токенизатором, остановка и освобождение native-ресурсов.
CPU, 2 потока, low memory/precision, без HTTP-загрузчика MNN и GPU.
API и SHA исходников закреплены; сторонних неофициальных Maven-библиотек нет.

Модель официально ориентирована на английский и китайский. Русский, следование
инструкциям и фактическая точность не гарантированы. Карточки рекомендаций
строятся только по строгому JSON-массиву допустимых идентификаторов реальных кандидатов. Ответы со скопированным списком или посторонним текстом отклоняются. Свободный
текст модели всё ещё может содержать ошибки. Без подходящих идентификаторов
кнопок нет; произвольные URL из ответа не превращаются в переходы.

## Воспроизводимая сборка

Нужны полный JDK 17, Android SDK 37, NDK 27.2.12479018, CMake 3.22.1 и штатный
`app/google-services.json` (как в основном приложении). Схема Room не менялась.

```sh
git switch feature/local-ai-mnn-pocket
git submodule update --init third_party/MNN
./gradlew :app:testDebugUnitTest :local-ai:testDebugUnitTest --max-workers=2
./gradlew :app:lintDebug :local-ai:lintDebug --max-workers=2
./gradlew :app:assembleDebug :app:compileDebugAndroidTestKotlin -PincludeMnnRuntime=true --max-workers=2
```

Без `-PincludeMnnRuntime=true` MNN в APK не включается и вход в чат скрыт.
APK: `app/build/outputs/apk/debug/app-debug.apk`. Существующие зависимости могут
добавлять другие ABI, но MNN работает только на `arm64-v8a`.

## Реальные проверки модели

На Linux x86_64 можно проверить официальный экспорт тем же MNN CPU runtime:

```sh
python3 tools/local_ai/download_model.py /absolute/path/pocket-model
tools/local_ai/run_host_probe.sh /absolute/path/pocket-model /absolute/path/results
```

Probe использует reset, chat template, настоящий tokenizer, prefill и пошаговую
генерацию до EOS/256 токенов. 20 русских запросов — `tools/local_ai/russian-prompts.txt`.
Выход: сырые ответы `0.txt`…`19.txt` и `metrics.tsv`. Это проверка CPU/runtime,
а не Android/JNI, ARM64, UI или измерение скорости телефона.

На ARM64-устройстве установите модель через UI, затем:

```sh
./gradlew :app:connectedDebugAndroidTest -PincludeMnnRuntime=true \
  -Pandroid.testInstrumentationRunnerArguments.class=com.sergey.animevault.localai.LocalAiDeviceProbe \
  -Pandroid.testInstrumentationRunnerArguments.runLocalAi=true
adb exec-out run-as com.sergey.animevault cat no_backup/local-ai/probe.json > probe.json
```

Для проверки offline после установки отключите Wi-Fi/мобильную сеть. Отдельно
проверьте остановку, фон/возврат, поворот, восстановление процесса, отмену
установки, недостаток места/RAM, отказ SAF, ошибки каталога и переходы из карточек.
Отсутствие устройства не считается успешным прохождением этих сценариев.

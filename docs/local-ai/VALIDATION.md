## Реальная генерация

Собран MNN CPU runtime для Linux x86_64, 2 потока, low memory/precision,
тот же reset → chat template → tokenizer → prefill → `generate(1)`, что в JNI.
Все веса официальные, неизменённые. Лимит ответа 256 токенов, входа 1792.

20 русских запросов выполнены с системной инструкцией приложения:
`Answer briefly in Russian. If you do not know, say so. Do not invent facts.`

- 20 непустых ответов, 1375 сгенерированных токенов, exit code 0;
- 16 завершений EOS, 4 достижения лимита 256 токенов;
- загрузка 2479 мс; TTFT 129–8495 мс;
- VmHWM процесса при чтении `/proc`: 296 008 KiB, около 289 MiB RSS.

**Это не benchmark телефона.** Начальные запросы конкурировали с Gradle за
2 CPU. Сборка была остановлена, чтобы закончить inference, затем возобновлена
из сохранённых промежуточных файлов. Показатели времени непригодны для сравнения
устройств. RSS Linux не равен Android PSS или минимально необходимой RAM.

## Реализованное поведение

- Существующие `LocalAiEngine`, JNI, UTF-8 streaming, stop и token budget сохранены.
- `PocketModelStore`: pinned HTTPS-загрузка, прогресс, отмена HTTP-вызова,
  проверка свободного места, размера/SHA-256, staging и замена с восстановлением.
  До установки старая модель выгружается. При ошибке копирования она сохраняется.
- Ручной импорт официальной папки через SAF; произвольный конфиг не исполняется.
- Отдельный Compose-экран из главного меню, потоковый вывод, stop, очистка истории,
  удаление модели, сообщения об ошибках. Вход скрыт в сборках без MNN.
- Переписка атомарно сохраняется в приватный файл, без изменения Room-схемы.
  При остановке сохраняется частичный ответ. На уходе в фон runtime выгружается.
- Кандидаты из `LibraryRepository`, сохранённых произведений и опционально
  `OnlineRepository.getCatalog`. Кнопки ведут в существующие local/online routes.
- Нет модели — отправка отключена. Недостаток RAM, неподдерживаемая ABI,
  переполнение контекста, ошибки HTTP/SAF/целостности имеют сообщения восстановления.

## Оставшиеся ограничения

1. Русский язык и подбор Pocket непригодны для заявления готовой функции.
   Нужна отдельная оценка совместимой многоязычной модели или обучение/экспорт;
   другой моделью эта задача не подменялась.
2. Нет ADB-устройства (`adb devices -l` — пусто). Не выполнены Android inference,
   установка APK, UI, TalkBack, повороты, process recreation, offline/airplane,
   реальная Android-загрузка/SAF, переходы и регрессия плеера/каталога на устройстве.
3. Порог 512 MiB — эвристика. Native abort и Android low-memory killer не
   перехватываются; требование RAM на телефоне не измерено.
4. Загрузчик работает только при активном экране; целые проверенные файлы
   переиспользуются, незаконченный файл скачивается заново. Нет HTTP Range resume
   и фонового WorkManager-загрузчика. Android-доступ к Hugging Face зависит от сети.
5. Принимается только закреплённый официальный комплект. Нет выбора иных моделей,
   GPU или других ABI. Модель/чат не входят в backup/export и удаляются с приложением.
6. Одна история до 60 сообщений, контекст 2048, ответ до 256 токенов.
   Рекомендации видят до 12 кандидатов с одной страницы/из библиотеки, а не весь
   каталог; метаданные могут быть неполными. Извлечение поисковой фразы моделью
   также ненадёжно. Ошибка провайдера и пустой набор обрабатываются отдельно.
7. Полезность рекомендаций не гарантируется даже при валидном ID; строгий формат
   защищает маршрутизацию, но не качество выбора.

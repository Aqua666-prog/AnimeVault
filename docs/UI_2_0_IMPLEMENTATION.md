# AnimeVault UI 2.0

Рабочая ветка: `feature/ui-redesign-2`.
Основа: `feature/tenrai-final-v5`, коммит `9c369fb243fb3c08c28883f69ac166273ad9fdaa`.

## Реализовано в исходниках

- Дизайн-система Vault Lemon Purple: семантические цвета, типографика, формы, интервалы и длительности. Лимонный выделяет просмотр, прогресс и активный раздел; фиолетовый — навигацию и вторичные действия. Компоненты используют тему и общие токены.
- Темы Vault Lemon Purple и AMOLED Lemon Purple. Устаревшие сохранённые названия тем читаются совместимо и отображаются как Vault; OLED сохраняется. Параметры находятся в «Настройки → Интерфейс».
- Пять основных разделов: Главная, Каталог, Библиотека, Загрузки, Настройки. На широком экране используется боковая панель. Папки, история, статистика, клипы и прежнее управление онлайн-библиотекой остаются доступны.
- Главная с backdrop, названием, метаданными, жанрами, описанием, просмотром и добавлением в избранное. Продолжение просмотра объединяет существующий локальный и онлайн-прогресс, показывает оставшееся время и сразу открывает серию. Подборки скрываются при отсутствии данных.
- Общий Hero онлайн- и офлайн-тайтлов. Backdrop выбирается из AniList banner → metadata poster/picture → provider poster → фирменный фон. Ошибка загрузки переключает на следующий кандидат. Используется Crop и затемняющий градиент; пропорции изображений сохраняются.
- Динамический оттенок artwork включается отдельно от темы. До 256 пикселей программного bitmap анализируются на Dispatchers.Default один раз после загрузки; результат даёт слабый оттенок backdrop. Кнопки, текст и основная палитра остаются фирменными.
- Страница тайтла разделена на вкладки: серии, описание и дополнительные данные/источники. Сверху появляются название и непрозрачный AppBar при прокрутке; backdrop затемняется, в полном режиме доступен слабый parallax. Сохранены озвучки, связанные источники, AniList, Tenrai, OP/ED и дополнительные метаданные.
- Действия серии: смотреть, скачать для онлайн-источника, отметить просмотренной/непросмотренной. У офлайн-серий остаётся группировка. Можно отметить сезон просмотренным. Tenrai-title, дата, filler/recap и статус загрузки показаны компактно.
- Каталог: поиск, источник, фильтры жанра/года/типа/статуса/количества серий/оценки, сортировка, сетка постеров. Расписание Tenrai, текущий сезон и будущий сезон открываются отдельно; выбор запускает поиск у реальных провайдеров. Случайный тайтл сохранён в дополнительном меню.
- Библиотека: продолжение, избранное, буду смотреть, просмотрено, брошено, на устройстве и все тайтлы. Оригинальные источники прогресса и онлайн-избранного используются напрямую. Новая принадлежность списку и локальное избранное хранятся отдельно в UiPreferences, без миграции Room.
- Загрузки: постер из существующей онлайн-библиотеки, тайтл, серия, качество, размер, лимонный прогресс, очередь/загрузка/пауза/готовность/ошибка. Управление и подтверждение удаления сохранены.
- Media3-плеер: лимонная кнопка и шкала, короткий fade контролов, прокрутка панели действий, блокировка касаний, ±10 секунд по двойному тапу. Сохраняются озвучка/качество, субтитры, скорость, масштаб, следующая серия, автопропуск, таймер сна, эквалайзер, PiP и AnimeVault enhancer. Включение enhancer показывает короткое сообщение.
- Полные, уменьшенные и отключённые собственные анимации; отдельный режим уменьшенного движения. Системное отключение аниматоров переводит собственные эффекты в OFF. В уменьшенном режиме нет parallax, press-scale и shared-element. Загрузочные placeholders статичны, без отдельных бесконечных аниматоров для каждой ячейки.
- VA-монограмма используется в UI, заставке, адаптивном и монохромном launcher icon; добавлены обычные ресурсы иконки для API 24–25.
- Vault Reveal: 1800 мс, шов → раскрытие → V → A → краткий лимонный блик → интерфейс. Показывается один раз за процесс при запуске с главного экрана. Восстановление Activity, глубокие ссылки и тёплый повторный запуск пропускают заставку. Уменьшенный вариант — 220 мс; OFF сразу показывает приложение.

## Архитектура и ограничения

Провайдеры, unified online search, клиенты Tenrai/AniList, Room-схема и сущности, MediaStore/SAF, DownloadRepository/WorkManager и владение Media3-плеером не переписаны. Новые поля относятся к UI-state и модели отображения. Версия приложения сохранена: 2.0.0, code 50; версия базы — 8. Зависимости и SDK проекта сохранены.

Новые списки и локальное избранное не добавлены в существующий формат ручного экспорта резервной копии. Онлайн-избранное продолжает храниться в оригинальной системе. Завершение одной онлайн-серии не считается завершением всего тайтла. Для локальных файлов категория «Просмотрено» определяется полным известным набором серий, если пользователь не выбрал другой список.

Оценки каталога доступны только для тайтлов с подтверждённым MAL ID, найденных в текущих ответах Tenrai. Без включённого фильтра отсутствие оценки не скрывает тайтл. При включённом фильтре тайтлы с неизвестной оценкой исключаются; это объяснено в интерфейсе.

Персонализированный рекомендательный алгоритм не добавлен. Главная использует существующий каталог и discovery-подборки, поэтому секция называется «Откройте для себя». Отдельная секция популярного скрыта, поскольку подтверждённый ранжированный список не подключён. Полный сервис рекомендаций выходит за рамки изменений UI.

Если для старой загрузки в онлайн-библиотеке нет постера, используется фирменный фон. Новое поле постера в сохранённую модель задания не добавлялось.

## Проверено в рабочем окружении

- `bash tools/verify-final.sh` — успешно: XML, sanity исходников, конфигурация 12 провайдеров, версия приложения и базы.
- `bash tools/verify-2.0.0.sh` — успешно: исходники, конфигурация, наличие ключевых частей загрузок и существующих проверок.
- `git diff --check` — успешно.
- Дополнительный разбор изменённых Kotlin-файлов tree-sitter-kotlin: новых синтаксических ошибок не обнаружено; известные ограничения грамматики на типах `@Composable () -> Unit` совпадают с базовой веткой. Это не компиляция и не проверка типов.
- Область diff проверена: изменений в `data/`, схемах Room, зависимостях, версиях, разрешениях и движках нет. Поправка tools/verify-provider-config.py добавляет существующий доверенный домен Animetka в проверочный скрипт, согласуя его с конфигурацией.

Добавлены/обновлены JVM-тесты для настроек движения, приоритета artwork, списков библиотеки, фильтра оценки и запрета повторной заставки. Они **не запускались**: окружение не содержит Android SDK, Gradle distribution не удалось скачать из-за недоступности сети. APK не собран. Instrumentation, просмотр реального UI, TalkBack и измерение FPS не выполнены.

CI `AnimeVault QA APK` настроен на `feature/ui-redesign-*`: JVM-тесты → lint → debug APK. Имя артефакта содержит SHA коммита. Автоматический push в GitHub недоступен текущей интеграции; ветка передаётся в git bundle. После обычного push CI должен быть запущен и проверен владельцем репозитория.

## Проверка перед признанием версии готовой

В окружении с JDK 17, Android SDK 37 и доступом к зависимостям:

```bash
./gradlew --no-daemon testDebugUnitTest lintDebug assembleDebug
```

| Сценарий на реальном APK | Критерий |
| --- | --- |
| Холодный/тёплый запуск, поворот, глубокая ссылка | Заставка только при первом холодном запуске; повторного блокирующего intro нет |
| Vault/AMOLED, Dynamic Artwork, движение OFF/Reduced, Android animator scale 0 | Сохранение настроек, читаемый текст, отсутствие полной заставки и крупных собственных эффектов при ограничении движения |
| Главная → каталог → поиск → тайтл → озвучка → серия → Media3 | Рабочий поток и единый Lemon Purple UI |
| Выход из плеера → продолжить с главной и библиотеки | Возврат к сохранённой позиции, корректный лимонный прогресс |
| Скачать → пауза → продолжить → готово → офлайн-просмотр | Состояния совпадают с движком, серия открывается без сети |
| Избранное/списки, серия просмотрена/непросмотрена, весь сезон | Значения сохраняются после перезапуска; список не подменяет прогресс |
| Плеер: двойной тап, блокировка, субтитры, качество, скорость, enhancer, PiP | Действия доступны; касания заблокированы до явной разблокировки; сообщение enhancer исчезает |
| Ошибка AniList/Tenrai/provider poster и отсутствие сети | Запасной artwork, понятная ошибка/повтор, прежние offline-функции доступны |
| Узкий телефон, landscape, планшет, крупный шрифт, TalkBack | Нет обрезанных основных действий; управление достижимо одной рукой |
| Скролл каталога/тайтла на устройстве среднего класса | Проверить frame timing и 60 FPS; по исходникам это не подтверждается |

До успешной сборки и полного сценария на APK критерий готовности ТЗ **не подтверждён**.

# AnimeVault 0.7.2

## Каталог

- карточки онлайн-каталога стали компактнее: на обычном телефоне помещается больше тайтлов без потери основных метаданных;
- источник больше не дублируется на каждой карточке, потому что он уже выбран в верхней панели;
- статус «выходит» и число доступных/заявленных источником эпизодов вынесены на постер;
- тематические подборки заменены на компактную горизонтальную ленту;
- счётчики подборок теперь прямо помечены как относящиеся только к уже загруженной части каталога;
- над сеткой показывается честная сводка: сколько релизов загружено, сколько прошло фильтры и сообщает ли источник о следующей странице;
- вместо ложного общего числа каталога приложение показывает фактическое число загруженных карточек и текущую страницу.

## Совместимость

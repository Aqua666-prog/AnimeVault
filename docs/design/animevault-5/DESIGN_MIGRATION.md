# План миграции интерфейса AnimeVault 5.0

Исходная точка — 4.2.0, `aad02e0`. Выбор направления и запуск работ над production UI утверждает владелец. Design Discovery реализует только debug Compose с фикстурами. Адаптация маршрутов ниже сохраняет доступность всех операций из [аудита](DESIGN_AUDIT.md).

Записать метрики 4.2 для cold start, прокрутки и запуска Media3 | Владелец утвердил приоритет, навигацию и бюджет изменений. Есть воспроизводимая база |

Для согласованного дизайна обновить production UI goldens в том же изменении, где меняется соответствующий экран.

## Проверки совместимости

- **Хранилище.** Фикстуры существующих backup, Room migrations, ключи источников и прогресса, локальное распознавание, избранное, SAF URI, идентичность импортированного медиа и состояние work при обновлении.
- **Доступность.** TalkBack проверяет порядок фокуса, роли вкладок и прогресса, крупный шрифт и управление без жестов. Для плеера важны доступность перемотки, закрытие панели системным Back и субтитры.
- **Устройство.** Минимальная версия и современный Android, обычный телефон и широкий планшет, landscape, жестовая и кнопочная навигация, системный motion 0, плохая сеть, потеря хранилища, остановка процесса.
- **Производительность.** Сопоставить время первого кадра и продолжения серии, холодный старт, jank на крупных списках, память изображений и прогресс живой очереди. Собирать одинаковые трассы на тех же устройствах и отдельно проверять API 24.

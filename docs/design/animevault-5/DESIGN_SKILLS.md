# Навыки и происхождение методов

Архивы исходников изучались по зафиксированным коммитам вне рабочего дерева. Проверка охватывала применённые инструкции, лицензии, manifest/dependency declarations, установочные команды, hooks и точки запуска. Транзитивные npm/Bun пакеты и скачиваемые исполняемые файлы целиком не аудировались. Для работы использованы тексты методик. Установки навыков, запуска hooks, browser runners, Bash/JS-лаунчеров, локальных веб-серверов и команд загрузки бинарников не было. Пользовательские навыки и конфигурация окружения сохранены.

## Дополнительные источники

- **Android adaptive / edge-to-edge** от Google, [7f7b217, Apache-2.0](https://github.com/android/skills/tree/7f7b21730a605d112ca9f79b6e40105ce7b670ee). Использованы проверка доступной ширины, отдельный альбомный режим, сохранение состояния списка при Back и единое владение insets в плане интеграции. Предлагаемые новые API Navigation 3 и Compose MediaQuery не нужны для сравнения.

Дали карту зависимостей и точек входа, выбор render harness и ручную проверку PNG по состояниям, масштабу и ориентации. [Android test references](https://github.com/android/skills/tree/7f7b21730a605d112ca9f79b6e40105ce7b670ee/testing/testing-setup).

Композиция и идентичность следуют собственным контрактам, а типографика и движение проверены по `typeset` и `animate` из impeccable.

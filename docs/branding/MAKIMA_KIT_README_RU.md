## Что именно является исходником

Утверждённый рисунок сохранён без изменения байтов: RGBA PNG 1254 × 1254.
Портрет без текста подготовлен отдельно с помощью генерации изображения; он может
незначительно отличаться от портрета в утверждённом полном логотипе.

PNG — растровое изображение. Исходного PSD с отдельными слоями волос, кожи и глаз
нет. SVG содержит встроенный растровый портрет и отдельно редактируемый текст;
это макет, а не полная векторизация рисунка. ORA содержит два растровых слоя:
портрет и надпись. Макеты SVG/ORA дают возможность менять расположение и масштаб
элементов, а SVG — также надпись и её цвета.

Надпись в редактируемом макете набрана DejaVu Sans Bold и может немного отличаться
от букв в утверждённом PNG. Для точного воспроизведения утверждённого варианта
используйте logo_approved.png. Шрифт в архив не включён; при его отсутствии
редактор может подставить другой sans-serif.

Прозрачный фон есть у исходных PNG, экспортов с transparent в имени и переднего
слоя адаптивной иконки. Тёмная подложка иконки Android задаётся отдельным ресурсом.
Файлы previews/ показывают результат на подложке и не заменяют прозрачные PNG.

## Подключение к Android-приложению

1. Скопируйте содержимое android/app/src/main/res/ в app/src/main/res/
   вашего проекта с объединением папок. Другие ресурсы проекта сохраняются.
2. В существующем элементе application файла AndroidManifest.xml укажите:

       android:icon="@mipmap/ic_animevault"
       android:roundIcon="@mipmap/ic_animevault_round"

   Файл integration/AndroidManifest.fragment.xml — пример атрибутов.
   Не заменяйте им весь AndroidManifest.xml.
3. Для логотипа внутри приложения используйте R.drawable.animevault_brand_logo,
   для портрета — R.drawable.animevault_brand_portrait.
4. Пример Compose находится в integration/AnimeVaultBrand.kt.example.
   Перенесите функцию в существующий UI-пакет, добавьте импорт своего R
   и задайте размер через modifier из вашей темы/компонента.
5. Обычный drawable с прозрачным логотипом предназначен для экранов приложения.
   Подключение системного splash screen выполняется отдельно.
6. Сборку и проверку APK выполняйте через существующий GitHub Actions workflow.

Имена ресурсов имеют собственный префикс. Существующие ic_launcher не нужно
удалять: манифест просто будет ссылаться на ic_animevault.

## Иконки и размеры

| Плотность | Обычная и круглая иконки | Передний слой adaptive |
| --- | --- | --- |
| mdpi | 48 × 48 | 108 × 108 |
| hdpi | 72 × 72 | 162 × 162 |
| xhdpi | 96 × 96 | 216 × 216 |
| xxhdpi | 144 × 144 | 324 × 324 |
| xxxhdpi | 192 × 192 | 432 × 432 |

Обычные PNG предусмотрены для Android 7.x и launchers без adaptive icons.
На Android 8.0+ используются XML из mipmap-anydpi-v26: отдельные фон и передний
слой. В иконке используется портрет без букв, чтобы сохранить читаемость.

Передний слой — 108 dp; портрет размещён в центральном квадрате 60 dp с запасом
относительно области 66 dp. Монохромный слой для themed icons в этот набор не
включён. Для детального портрета нужна отдельная графическая интерпретация.

Официальная документация Android:
https://developer.android.com/develop/ui/compose/system/icon_design_adaptive

## Повторный экспорт

Требуются Python 3 и ImageMagick, доступный как magick или convert.
Выполните из корня набора:

    python3 tools/build_assets.py

Скрипт пересоздаёт производные файлы набора, SVG/ORA-макеты и контрольные суммы.
Два исходных PNG не перезаписываются. Он работает локально, не вызывает модель
и не запускает Gradle, SDK или сборку APK. Для надписи нужен DejaVu Sans Bold,
если хотите получить тот же вид редактируемого макета.

## Проверка

VALIDATION.json содержит результат проверки изображений, размеров ресурсов,
XML и целостности исходников. SHA256SUMS.txt — контрольные суммы файлов.

Проверены подготовленные ресурсы и макеты. Установка на устройство, реальная
работа launcher и сборка приложения в рамках этого пакета не выполнялись.

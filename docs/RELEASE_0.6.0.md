# AnimeVault 0.6.0

## Что нового

- фильтр онлайн-каталога по жанрам текущего источника;
- сортировка по жанру, названию, новизне и году выхода;
- динамические тематические подборки: онгоинги, новинки, фэнтези, романтика,
  мистика и хоррор, история и самураи, комедии, экшен и короткие сериалы;
- жанры отображаются прямо на карточках релизов;
- фильтр жанра и тематическая подборка работают совместно;
- при пустом результате можно сбросить фильтры или загрузить следующую страницу.

## Совместимость

- `versionCode 11`, `versionName 0.6.0`;
- минимальная версия Android — API 24;
- схема Room не менялась;
- APK подписывается тем же сохранённым ключом, что и версии 0.3.1–0.5.2,
  поэтому устанавливается поверх них без потери настроек и прогресса.

Подборки формируются локально из уже загруженных страниц выбранного источника.
Если источник не передаёт жанры для каталога, жанровый фильтр отключается, но
подборки по статусу, году и числу серий остаются доступны.

# AnimeVault 0.2.0

Дата сборки: 11 августа 2026 года.

## Главное

- Независимые вкладки «Офлайн» и «Онлайн».
- Каталог и поиск через актуальный AniLiberty API v1.
- Постеры AniLibria, отдельная карточка для каждого релиза/сезона.
- Экран онлайн-релиза с описанием, жанрами, статусом и сериями.
- HLS-плеер Media3 с качеством 480p/720p/1080p, скоростью и автопереходом.
- Раздельное сохранение офлайн- и онлайн-прогресса.
- Ручной выбор обложки локального тайтла через SAF.

## Установка

Установите `AnimeVault-0.2.0-debug.apk`. Он подписан тем же debug-сертификатом,
что и предыдущая переданная сборка, поэтому может быть установлен поверх
AnimeVault 0.1.1. Схема Room остаётся версией 1: локальный каталог и прогресс
обновление не удаляет.

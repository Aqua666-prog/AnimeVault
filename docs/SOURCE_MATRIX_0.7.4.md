## Приоритет воспроизведения

Для каждого онлайн-релиза AnimeVault хранит предпочитаемую озвучку и последнее выбранное качество. При следующем запуске серии список потоков сортируется так:

1. сначала выбранная озвучка;
2. внутри неё - выбранное качество;
3. затем остальные рабочие варианты в исходном порядке провайдера.

Если конкретная озвучка или качество исчезли, приложение не блокирует запуск и использует доступный fallback.

## YummyAnime

Yummy намеренно сохраняет две независимые оси метаданных: `dubbing` и `player`. Несколько записей с одинаковым номером серии превращаются в один `OnlineEpisode` с несколькими `OnlineStream`.

Нативный Kodik resolver применяется только к явно распознанным Kodik embed. Неизвестные плееры не реверсятся вслепую и остаются `EMBED`.

## Что ещё стоит исследовать

- Studio Band: стабильный контракт плеера и наличие уникальных потоков сверх Kodik/агрегаторов;
- SHIZA Project, AniDUB и AniFilm: прямые контракты каталога/плеера;
- MoonAnime и Mikai: текущая стабильность и доля дублирования уже подключённых источников;
- health-check слой, который сможет временно помечать источник как degraded, не скрывая остальной объединённый каталог;
- локальный кэш результатов «Все источники» с TTL и дедупликацией фоновых запросов.

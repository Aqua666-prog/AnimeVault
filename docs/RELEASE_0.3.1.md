# AnimeVault 0.3.1

Исправляющий релиз после проверки 0.3.0 на реальном Android-устройстве.

## Изменения

- оставлены четыре источника: AniLiberty, AnimeLib, AnimeVost и Jut.su;
- удалены неработающие адаптеры YummyAnime, AnimeGo и Anixart и связанные с
  Anixart элементы авторизации;
- Jut.su теперь выбирает потоки только из `video#my-player` и использует один
  браузерный User-Agent для страницы и MP4;
- короткий или пустой медиаресурс больше не отмечает серию просмотренной и не
  запускает следующую серию;
- повреждённый прогресс Jut.su из 0.3.0 однократно очищается;
- AnimeLib использует браузерные заголовки API и помечен как beta из-за
  возможных ограничений `403` на стороне источника.

## Проверка на устройстве

Проверьте поиск и воспроизведение AnimeLib, а для Jut.su вставьте ссылку или
slug тайтла и запустите первую серию. Если источник отдаст заглушку, приложение
должно показать ошибку, не поставить галочку и не перейти к следующей серии.

## Установка

Готовый debug APK 0.3.1 подписан другим временным ключом, чем ранее выданный
debug APK 0.3.0. Для установки потребуется сначала удалить 0.3.0; Android при
этом удалит базу приложения и сохранённый прогресс, но не затронет видеофайлы.
APK, собранный тем же ключом, по-прежнему обновляется поверх без миграции Room.
Для сохранения данных перед удалением предусмотрены скрипты из
[`docs/MIGRATION_0.3.0_TO_0.3.1.md`](MIGRATION_0.3.0_TO_0.3.1.md). Все готовые
debug APK начиная с 0.3.1 должны подписываться сохранённым ключом из
[`docs/SIGNING.md`](SIGNING.md).

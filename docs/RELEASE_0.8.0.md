# AnimeVault 0.8.0

Дата сборки: 15 августа 2026 года.

## Главное

- AnimeON обновлён под актуальный API: список серий хранит `episodeId`, а `videoUrl` запрашивается при запуске просмотра.
- Поддерживаются актуальные плееры AnimeON Ashdi и Moon.
- YummyAnime работает без обязательного application token.
- Kodik-варианты AnimeLib передаются встроенному HLS-резолверу.
- Единый каталог показывает название исходного источника и настоящую причину ошибки загрузки.
- Jut.su больше не принимает `pixel.png` за видеоролик и не завершает серию сразу после запуска.

## Состояние источников на момент сборки

- AniLiberty: каталог, релизы и HLS отвечают.
- AnimeVost: каталог, плейлисты и MP4 отвечают.
- AnimeLib: каталог, серии и Kodik embed отвечают.
- AnimeON: поиск, переводы, серии и ссылки Ashdi/Moon отвечают.
- AniMedia, SameBand и AnimeBest: сайты и каталожные страницы отвечают.
- YummyAnime/Yani: каталог, карточки и видео отвечают без токена.
- Kodik: embed-плееры отвечают; публичный токен каталога может отвергаться, собственный API-токен остаётся поддержан.
- Jut.su: временно отключён, поскольку сервер возвращает изображения-заглушки вместо публичных видео URL.
- Dream Cast: временно отключён из-за HTTP 404 на страницах сайта.

## Установка

APK подписан тем же отладочным ключом, что и предыдущие сборки AnimeVault из этой рабочей серии. Версия имеет `versionCode 22`, поэтому должна устанавливаться поверх 0.7.9 без удаления пользовательских данных.

# AnimeVault 0.9.0 — Metadata Foundation

Первый этап развития после Zenith. Цель релиза — сделать локальную медиатеку богаче, не превращая сканирование папок в сетевую операцию.

## Что добавлено

- Пользовательский поиск метаданных AniList прямо со страницы локального тайтла.
- Поиск запускается вручную: AnimeVault не сканирует AniList массово и не делает сетевые запросы при обычном SAF-сканировании папок.
- Сохраняется только выбранная пользователем карточка.
- Для локального тайтла сохраняются AniList ID, MAL ID, названия, постер, баннер, описание, год, число серий, формат, статус, жанры, оценка и ссылка AniList.
- Если пользователь не назначал локальный постер, карточка медиатеки и hero автоматически используют постер выбранных метаданных.
- При отсутствии метаданных сохраняется дополнительный fallback на постер связанного онлайн-релиза.
- Метаданные можно обновить повторным поиском или полностью удалить без пересканирования файлов.
- Добавлена миграция Room 2 → 3; существующая медиатека и прогресс просмотра сохраняются.

## Стабильность

- В CI сначала запускаются unit-тесты, затем `assembleDebug`.
- В ходе статической проверки исправлен контракт GraphQL-ответа: поле `Page` запрашивается через стабильный alias `page`, чтобы DTO корректно разбирал результат.
- GitHub Actions обновлён до `actions/checkout@v6` и `actions/setup-java@v5`.
- Сохранены исправления реальной сборки 0.8.5: публичные Gradle-репозитории, Unix wrapper, Compose imports/opt-ins.

## Следующий этап

После стабилизации этого слоя можно переходить к осторожному автоматическому сопоставлению тайтлов с confidence score и подтверждением сомнительных совпадений.

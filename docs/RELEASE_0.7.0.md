# AnimeVault 0.7.0

## Главное

Этот выпуск посвящён приоритету №1: офлайн-библиотека получила полноценный
Media Scanner, ручную перегруппировку и устойчивые связи с онлайн-релизами.

## Изменения

- SAF рекурсивно сканирует несколько выбранных корневых папок;
- при разрешении на медиатеку MediaStore дополняет видео длительностью и
  системными метаданными, но приложение продолжает работать и без разрешения;
- `EpisodeNameParser` распознаёт `S01E05`, `1x05`, `E05`, русские обозначения,
  диапазоны серий, дробные номера и ревизии `[05v2]`;
- сезон входит в ключ автоматической группировки и всегда остаётся отдельной
  карточкой;
- long-press по серии включает множественный выбор;
- выбранные серии можно объединить с существующей карточкой, отделить в новую
  или вернуть под управление автоматического парсера;
- ручные решения переживают пересканирование;
- офлайн-тайтл можно связать с несколькими онлайн-релизами через поиск по
  названию; сохраняются ID источника, MAL/Kodik ID и постер, если они доступны;
- на карточке тайтла показываются прогресс и число онлайн-связей;
- добавлено ежедневное фоновое пересканирование WorkManager, которое можно
  отключить в настройках;
- Room обновлён до версии 2 с явной недеструктивной миграцией `1 → 2`.

## Совместимость

- `applicationId`: `com.sergey.animevault`;
- `versionCode`: 12;
- `versionName`: 0.7.0;
- минимальная версия Android: API 24;
- APK подписывается сохранённым ключом версий 0.3.1–0.6.0;
- миграция сохраняет существующие папки, серии, прогресс и настройки.

## Быстрая проверка на телефоне

1. Установить APK поверх 0.6.0 и убедиться, что старая библиотека открывается.
2. Добавить две папки, в том числе вложенную структуру с `S01E01` и `S02E01`.
3. Отказать в разрешении на медиатеку: SAF-сканирование всё равно должно
   завершиться.
4. Удержать серию, отделить её в новый тайтл и нажать «Пересканировать» — новая
   карточка должна сохраниться.
5. Объединить серию обратно и проверить сохранённый прогресс.
6. Связать локальный тайтл с Kodik или AniLiberty и открыть связь с карточки.
7. Отключить и снова включить фоновое пересканирование в настройках.

## Пока не входит в выпуск

Жесты плеера, PiP, автоскип, избранное, пользовательские теги и экспорт/импорт
базы вынесены в следующие инкременты. Подробности — в `docs/ROADMAP.md`.

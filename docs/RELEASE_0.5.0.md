# AnimeVault 0.5.0

Релиз переводит Kodik с обязательного iframe на собственный плеер Media3.
Приоритет этого этапа — реальное воспроизведение, а не декоративные контролы.

## Что изменилось

- онлайн-плеер вынесен в отдельную полноэкранную `PlayerActivity`;
- Kodik iframe разбирается в прямые HLS-потоки 360/480/720p;
- запросы к плееру, player-JS, API и сегментам получают корректные
  `User-Agent`, `Referer` и `Origin`;
- ссылки `//kodik.info`, `//kodikplayer.com`, `//aniqit.com` и `//anivod.com`
  нормализуются в `https:`;
- качество переключается нативно без открытия новой веб-страницы;
- добавлен публичный `directIntent` для готовой `m3u8` или ссылки Kodik;
- ошибки Media3 пишутся в Logcat с тегом `AnimeVaultPlayer` и показываются
  пользователю через Toast и сообщение поверх плеера;
- при изменении разметки Kodik штатный провайдер оставляет WebView как fallback;
- добавлены unit-тесты параметров iframe, динамического API-пути, качеств,
  заголовков, `//`-ссылок и старого ROT+Base64 формата;
- минимальная версия Android снижена до API 24;
- версия повышена до `0.5.0` (`versionCode 8`).

## Как проверить на телефоне

1. Установите APK поверх AnimeVault 0.3.1–0.4.1.
2. Откройте «Онлайн → Kodik», найдите релиз и выберите озвучку.
3. Нажмите серию. Должна открыться отдельная полноэкранная Activity, а видео —
   запуститься стандартным контроллером Media3.
4. Нажмите `HQ`: для доступного релиза должны появиться варианты 360/480/720p.
5. Проверьте паузу, перемотку, время, смену качества, кнопку назад и следующую
   серию после завершения.
6. При ошибке откройте Logcat и отфильтруйте тег `AnimeVaultPlayer`.

## Обновление

APK подписан тем же сохранённым ключом, что и сборки начиная с 0.3.1. Схема
Room не менялась, поэтому подключённые папки и прогресс сохраняются.

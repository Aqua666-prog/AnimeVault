# AnimeVault 0.9.1 — Matchmaker

Этап 2 развития локальных метаданных. Цель — автоматически находить очевидные совпадения, но не превращать fuzzy matching в источник ложных карточек.

## Умное сопоставление

- При первом открытии локального тайтла без метаданных AnimeVault выполняет один осторожный поиск AniList.
- SAF-сканирование папок остаётся полностью локальным: массового сетевого обхода библиотеки нет.
- Для оценки используются online alias, название связанного релиза, подсказка из имени файла, локальное название, количество найденных серий и MAL ID связанного онлайн-релиза.
- Кандидаты получают confidence score `0–100` и уровни `VERIFIED / HIGH / MEDIUM / LOW`.
- Только точное совпадение MAL ID считается `VERIFIED` и может быть сохранено автоматически.
- Сильное совпадение по названию/сериям не сохраняется молча: на карточке появляется предложение «Похоже, это …» с кнопками подтверждения и выбора другого результата.
- Сомнительные совпадения остаются только в ручном поиске.

## Ручной поиск

- Результаты AniList теперь сортируются локальным matcher'ом, а не только порядком поисковой выдачи.
- У каждого кандидата виден процент уверенности и краткие причины: совпадение названия, alias, числа серий или внешнего ID.
- Низкая уверенность не запрещает ручной выбор, поэтому редкие русские/альтернативные названия не блокируются алгоритмом.

## Надёжность

- Автоматический и ручной поиск делят кэш AniList; параллельные запросы сериализованы, чтобы один экран не отправлял дубликаты.
- Автопоиск ждёт появления реальных серий локального тайтла и не стартует на промежуточном пустом состоянии Room.
- Ошибка сети не влияет на воспроизведение, SAF, Room и ручное управление локальной медиатекой.
- Схема Room не менялась; миграция после 0.9.0 не нужна.

## Проверки

- Добавлены unit-тесты VERIFIED-сопоставления по MAL ID.
- Проверяется high-confidence совпадение по alias + числу серий.
- Проверяется нормализация `_`, `-`, `/`, пунктуации и регистра.
- Проверяется защита от нерелевантного кандидата, ranking и штраф за сильное расхождение числа серий.

# AnimeVault 0.9.2 — Home

Этап 3: единый домашний экран поверх уже существующих локальной медиатеки, истории и онлайн-библиотеки.

## Главная

- AnimeVault теперь открывается на `Home`, а не сразу в локальной сетке.
- Быстрые действия ведут в локальную медиатеку и онлайн-каталог без дублирования их функций.
- Сводная карточка показывает число локальных тайтлов, серий, просмотренных и оставшихся серий.

## Продолжить просмотр

- Room отдаёт по одному последнему незавершённому локальному эпизоду на тайтл.
- Онлайн-прогресс берётся из существующего `OnlineLibraryStore`; отдельная история не создаётся.
- Локальные и онлайн-элементы объединяются только в presentation-слое и сортируются по фактическому времени просмотра.
- Нажатие на локальную карточку сразу открывает локальный плеер, на online-карточку — соответствующий online episode.
- Прогресс визуально отражает реальную позицию просмотра и не падает при неизвестной длительности.

## Дополнительные полки

- `Недавно добавлено` строится из существующей Room-медиатеки.
- `Избранное онлайн` использует уже существующий online favorites store.
- Пустой Home предлагает добавить локальную медиатеку, не создавая новый onboarding-state.

## Архитектурные границы

- Room schema не менялась, миграция не нужна.
- SAF scanner, grouping, metadata matching, online providers и Media3 playback не изменялись.
- Home является read-only агрегатором существующих источников данных.

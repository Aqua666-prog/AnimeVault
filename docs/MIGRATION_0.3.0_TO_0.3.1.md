# Перенос данных с 0.3.0 на 0.3.1

Готовые debug APK 0.3.0 и 0.3.1 подписаны разными ключами, поэтому Android не
может обновить приложение на месте. Скрипты в `tools` сохраняют данные debug-
сборки 0.3.0 через ADB, удаляют её только после проверки архива, устанавливают
0.3.1 и восстанавливают базу и обычные настройки.

## Что переносится

- каталог офлайн-файлов и локальный прогресс из Room;
- онлайн-прогресс и выбранный источник;
- подключённые URI папок как записи базы.

SAF-разрешения Android после удаления приложения восстановить нельзя, поэтому
папки нужно добавить повторно. Зашифрованный токен AnimeLib не переносится:
его ключ Android Keystore удаляется вместе с 0.3.0, поэтому токен вводится заново.

## Подготовка

1. Установите [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools).
2. Включите на телефоне режим разработчика и USB-отладку.
3. Подключите и разблокируйте телефон, подтвердите его RSA-ключ.
4. Распакуйте миграционный архив целиком. APK и скрипт должны лежать рядом.
5. Полностью закройте AnimeVault.

## Запуск

- Windows 10/11: запустите `migrate-0.3.0-to-0.3.1.cmd`.
- Linux/macOS: выполните
  `./migrate-0.3.0-to-0.3.1.sh`.

Скрипт не удаляет 0.3.0 до тех пор, пока локальный tar-архив не создан и в нём
не найден `databases/anime_vault.db`. Перед удалением требуется вручную ввести
`MIGRATE`. Файл `animevault-0.3.0-backup.tar` остаётся рядом со скриптом после
успеха; не удаляйте его до проверки библиотеки и прогресса.

Архив может содержать личную историю просмотра и настройки. Не публикуйте его.

## После переноса

1. Откройте 0.3.1.
2. Повторно добавьте папки с видео, чтобы Android выдал новые SAF-разрешения.
3. При необходимости повторно вставьте токен AnimeLib.
4. Проверьте локальный прогресс и один релиз каждого онлайн-источника.

Jut.su-прогресс из 0.3.0 намеренно очищается при первом запуске 0.3.1, поскольку
старая версия могла ошибочно отметить все серии просмотренными.

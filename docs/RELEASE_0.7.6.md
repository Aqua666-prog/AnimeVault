# AnimeVault 0.7.6

0.7.6 превращает online-режим из простого каталога в личную медиатеку и переносит выбор серий прямо в плеер. Схема Room не менялась.

## Личная онлайн-медиатека

- добавлен отдельный persistent-store метаданных онлайн-релизов;
- хранятся избранное, время первого/последнего открытия, последний просмотр, серия, позиция и длительность;
- обычная история ограничивается 500 последними тайтлами, при этом избранные записи никогда не удаляются автоматическим pruning;
- новый экран «Моя медиатека» разделён на «Продолжить», «Избранное» и «История»;
- карточка содержит постер, источник, последнюю серию и индикатор прогресса;
- из «Продолжить» серия запускается одним нажатием;
- массовая очистка истории и избранного требует подтверждения и не затрагивает соседний раздел;
- страница онлайн-тайтла получила кнопку избранного.

## Онлайн-каталог

- над основной сеткой появляется полка «Продолжить просмотр» из последних незавершённых тайтлов;
- полка не мешает поиску и скрывается при активном поисковом запросе;
- переход с полки возможен как на карточку тайтла, так и сразу в последнюю серию.

## Онлайн-плеер

- добавлена панель со всеми доступными сериями релиза;
- панель открывается поверх видео и прокручивается к текущей серии;
- текущая серия выделена, завершённые серии отмечены, частичный прогресс показан полосой;
- выбор серии запускает её через тот же `PlayerActivity` и сохраняет provider/release context;
- при сохранении позиции `OnlinePlayerViewModel` сразу обновляет progress map текущего playback state, чтобы панель серий не отставала от фактического просмотра.

## Хранение данных

- новая online library намеренно не добавляет таблицы в Room: локальная БД остаётся источником истины только для физической медиатеки;
- онлайн-метаданные хранятся отдельно в SharedPreferences в JSON-записях по ключу `providerId|releaseId`;
- существующий `OnlineProgressStore` продолжает отвечать за позицию конкретной серии;
- очистка истории не сбрасывает playback position, поэтому пользователь не теряет точку возобновления случайно;
- завершённая серия исключается из «Продолжить», но остаётся доступной в истории.

## Инфраструктура

- `versionCode 18`, `versionName 0.7.6`;
- схема Room без изменений относительно 0.7.5;
- добавлены unit-тесты вычисления continue-state и прогресса online library entry.

## Проверки

Перед упаковкой выполняются `git diff --check`, XML parse, структурная проверка всех Kotlin-файлов и проверка ZIP. Полный Android `assembleDebug` / `testDebugUnitTest` остаётся зависим от доступности Gradle 9.5.0 и Android SDK в окружении сборки.

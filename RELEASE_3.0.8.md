# AnimeVault 3.0.8 (68) — Cinematic Entrance

База: main `4cf51c7`. Ветка: `feature/cinematic-entrance`.

## Переработанный вход

Прежний переход между двумя разными портретами убран. На всём протяжении
заставки используется один утверждённый логотип из комплекта, без изменения
его файла, пропорций или надписи.

- 0–180 мс: тёмная сцена и нарастающее фиолетовое освещение.
- 180–1000 мс: логотип раскрывается из центра через мягкую прозрачную маску.
  Приближение 1.065 → 1.0 и подъём на 14dp плавно затухают к 1150 мс.
- 800–1400 мс: проявляются световая линия и небольшая подпись ENTER THE VAULT;
  наклонные орбиты, угловые направляющие и 14 редких частиц создают глубину.
- 1150–1630 мс: логотип неподвижен, декоративные детали начинают уходить.
- 1630–2100 мс: весь слой растворяется поверх существующего экрана приложения.

Таймлайн конечный: 2100 мс при обычном системном масштабе анимации.
Перед ним допускается **до 250 мс** на подготовку локального изображения;
успех/ошибка декодирования снимают ожидание раньше. Таймаут не даёт зависнуть.
Coil уже присутствует в проекте. Декодирование асинхронное, запрос ограничен
768px; использован один ограниченный размерами логотипа offscreen-слой для
маски, два градиента света, два эллипса, 14 точек. Нет видео, blur, новых
зависимостей или бесконечной системы частиц. Кадровые значения читаются в
Canvas/graphicsLayer/drawWithContent, не требуют перекомпозиции всего экрана.

Сохраняются launch gate, пропуск для deep links/восстановления, уменьшенных и
выключенных анимаций, касание/Back и завершение при уходе в фон/новом Intent.
Изображение вписано в обе оси доступного окна; декоративная подпись скрывается
при малой высоте и увеличенном шрифте. API 24+ остаётся минимальным требованием.

## Предпросмотр

[Открыть HTML-макет](docs/branding/cinematic-entrance-preview.html) локально после
клонирования репозитория. Есть повтор и ползунок времени, сеть не нужна.
Это отдельный браузерный дизайн-макет, **не запись Android-приложения**;
его тайминг и композиция согласованы с Compose, но не доказывают работу на GPU
Android или точное совпадение системных шрифтов и insets.

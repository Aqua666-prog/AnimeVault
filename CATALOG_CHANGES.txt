AnimeVault 0.7.7 — названия опенингов и эндингов

Что изменено:
- новый блок «Музыка» в карточке онлайн-тайтла;
- OP/ED показывают название, исполнителя и диапазон серий, когда эти данные доступны;
- длинные списки тем сворачиваются и раскрываются без перегрузки карточки;
- MAL ID используется как основной ключ; Shikimori ID может быть преобразован в MAL ID;
- при отсутствии ID работает консервативный fallback-поиск Jikan по названию, году и типу;
- метаданные тем не блокируют загрузку релиза и имеют отдельный retry;
- добавлены cache/throttle для публичного Jikan API и parser tests;
- versionCode 19, versionName 0.7.7; схема Room не менялась.

AnimeVault 0.7.6 — личная онлайн-медиатека и список серий

Что изменено:
- новый экран «Моя медиатека»: продолжить, избранное и история;
- persistent online library хранит метаданные тайтла, последнюю серию и прогресс отдельно от Room;
- сердечко избранного на странице онлайн-релиза;
- полка «Продолжить просмотр» над онлайн-каталогом;
- список серий прямо поверх нативного онлайн-плеера с прогрессом и отметками просмотра;
- быстрый переход на любую серию без возврата в карточку тайтла;
- подтверждение перед массовой очисткой истории или избранного;
- progress map плеера обновляется сразу после checkpoint;
- versionCode 18, versionName 0.7.6; схема Room не менялась.

AnimeVault 0.7.5 — жесты, PiP, автоскип и диагностика источников

Что изменено:

- восстановлен Unix gradlew;
- versionCode 17, versionName 0.7.5; схема Room не менялась.

AnimeVault 0.7.4 — современный интерфейс, SAF-фикс и YummyAnime

Что изменено:
- обновлена Material 3 палитра, бренд, вкладки, поиск, карточки каталога, тайтлов, серий и настроек;
- убран лишний runtime media permission после выбора папки через SAF, MediaStore-доступ вынесен в настройки;
- исправлены кириллические шаблоны EpisodeNameParser для «серия / эпизод / сезон / часть»;
- онлайн-плеер запоминает на уровне тайтла не только озвучку, но и последнее выбранное качество;
- исправлено проглатывание CancellationException в suspend-операциях и несколько гонок устаревших UI-ответов;
- обновлены R8/ProGuard keep-rules для Gson DTO/envelope всех провайдеров;
- внутренние AniLibria-имена переименованы в AniLiberty согласно фактическому источнику;
- сообщения настроек теперь различают успешные действия и ошибки;
- добавлен YummyAnime/Yani как 11-й прямой источник с application token из Android Keystore;
- варианты Yummy группируются по серии и сохраняют название озвучки и плеера;
- Kodik-варианты Yummy разрешаются существующим HLS-резолвером, остальные остаются embed fallback;
- versionCode 16, versionName 0.7.4; схема Room не менялась.

AnimeVault 0.7.3 — мульти-источники и новые каталоги

Что изменено:
- добавлен виртуальный источник «Все источники» с объединением карточек и озвучек;
- добавлены Dream Cast, AniMedia, AnimeON, SameBand и AnimeBest;
- добавлено сопоставление тайтлов по внешним ID и названию с защитой сезонов;
- потоки объединённой карточки сохраняют происхождение и разрешаются исходным провайдером;
- User-Agent теперь получает версию из BuildConfig вместо захардкоженной строки;
- добавлены parser/unit-тесты новых источников;
- versionCode 15, versionName 0.7.3.

Ограничения beta:
- AnimeON и AnimeBest сейчас используют поиск, а не полную постраничную ленту;
- SameBand ищет от 4 символов;
- постраничность единого каталога приблизительная, так как источники сортируют выдачу независимо;
- HTML-парсеры могут потребовать обновления после изменений на стороне сайтов.

AnimeVault 0.7.2 — правка онлайн-каталога

Что изменено:
- сетка стала плотнее: адаптивный минимум карточки 108 dp, уменьшены интервалы;
- карточки упрощены: источник не дублируется на каждой карточке, статус онгоинга и число эпизодов вынесены на постер;
- тематические подборки стали компактными chip-фильтрами вместо крупных плиток;
- добавлена сводка «Загружено / Показано» и текущая страница;
- счётчики подборок прямо обозначены как счётчики только по уже загруженной части каталога;
- приложение больше не создаёт впечатление, что число на первой странице равно полному размеру каталога;
- versionCode 14, versionName 0.7.2.

Важно:
В этот архив НЕ положен старый APK 0.7.1, чтобы его случайно не принять за новую сборку.
Для APK нужно собрать проект Gradle/Android Studio. Для обновления установленного приложения без удаления нужен тот же signing key, что и раньше.

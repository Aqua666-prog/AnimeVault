## Реализованная безопасная часть

Группы требуют общего внешнего ID того же namespace. Конфликт AniList/MAL/Shikimori,
явных сезонов/частей, формата или года более чем на один год запрещает объединение.
Каждый новый участник проверяется со всеми членами группы; порядок входных ответов
не влияет на состав и кодируемый список provider/release. Неполные ID приводят к
раздельным карточкам. Название никогда не доказывает идентичность.

Источник открывается по исходным provider/release. Ручное разделение сохраняется в
существующих SharedPreferences UiPreferences и действует при следующей загрузке каталога.
Разрешить объединение снова можно в исходной карточке. Рейтинг, история, локальные
связи и ID не перезаписываются. Группы всё ещё ограничены загруженной страницей.

Ранжирование: основное точное название 100, точный alias 95, нормализованное 90,
начало 75, все слова 65, подстрока 45, одна опечатка 30. Берётся один лучший критерий.
Используются NFKC, регистр ROOT, е/ё и пунктуация. Fuzzy разрешён для 5–80 символов,
не более 200 карточек и 16 aliases; это ранжирование известных результатов, не поиск
по всему локальному индексу. Работа выполняется на Dispatchers.Default.

Восстановление после ошибки не переходит к другому/неизвестному провайдеру без
подтверждения. Перед диалогом сохраняется snapshot позиции. Отмена не меняет
выбранный источник. Новый ExoPlayer и система прогресса не добавлены.

## Незавершённые требования

Это частичная реализация, PR должен оставаться draft. Не выполнены полная машина
состояний переключения, подтверждённое сопоставление типа/монтажа/длительности эпизодов,
полноценный chooser с проверенными возможностями каждого источника, opt-in автоматического
перехода, подсказки «Возможно, вы искали…» по всему локальному индексу, транслитерация,
дополнительные сигналы ранжирования, индикаторы локального прогресса на агрегированной
карточке, новые тесты полного жизненного цикла переключения и перезапуска настроек.
Для безопасного завершения нужны расширение provenance эпизодов и интеграционные
тесты перехода существующего playback session; одно совпадение номера серии нельзя
выдавать за доказанное соответствие. Существующие сохранённые настройки озвучки и
качества оставлены, но полный набор требований к Auto/ABR и межпровайдерному
сопоставлению студий этим изменением не подтверждён.

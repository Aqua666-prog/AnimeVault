# AnimeVault 1.7.2

Технический релиз надёжности загрузок, локального воспроизведения и сетевого слоя.

- Room стал источником состояния загрузок; старт приложения больше не блокируется `runBlocking`.
- Скачанная серия сохраняет единый прогресс в онлайн-истории и локальной медиатеке.
- Повторная загрузка другой озвучки или качества заменяет вариант одной логической серии.
- HLS BYTERANGE учитывает URI; сегменты и AES-128 обрабатываются потоково; HTTP 416 восстанавливает готовый partial-файл.
- Завершённые записи сверяются с файлами после восстановления Android Backup.
- Ручная ориентация локального плеера восстанавливается при выходе.
- «Мне повезёт» выбирает реальную случайную страницу и избегает десяти последних повторов.
- Общий HTTP connection pool переиспользуется провайдерами, параллелизм «Все источники» ограничен четырьмя запросами.
- WebView ограничивает переходы доверенными доменами; сторонние cookies включаются только нужным провайдерам.
- CI запускает исторические sanity-checks, блокирует APK при ошибке lint и поддерживает отдельную release-подпись.

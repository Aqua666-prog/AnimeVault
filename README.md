# AnimeVault

AnimeVault - Android-медиатека для аниме, объединяющая локальное хранилище, онлайн-каталог, историю просмотра и собственный плеер в одном медиапространстве. Приложение написано на Kotlin/Jetpack Compose, использует Media3, Room, WorkManager, Storage Access Framework и OkHttp.

Текущая версия разработки: **1.6.0** (`versionCode 42`), Android 7.0+ (API 24+).




## Что изменилось в 1.6.0 — Offline Downloads

- добавлена очередь офлайн-загрузок без торрентов на основе уже разрешённых `OnlineStream`;
- MP4 и HLS скачиваются в persistent Media3 cache через WorkManager, а `EMBED` намеренно не считается загружаемым;
- HTTP headers источника сохраняются в зашифрованном `SecureSessionStore`, поэтому AnimeLib/Kodik/AnimeVost/AnimeON не теряют `Authorization`, `Referer`, `Origin` и `User-Agent`;
- загрузки умеют паузу, продолжение, удаление, прогресс по байтам и persistent status после перезапуска;
- появился отдельный root-раздел `Скачивания`; завершённую серию можно открыть офлайн в собственном плеере AnimeVault;
- online detail получил кнопку загрузки у каждой серии и быстрый переход в очередь;
- офлайн-cache читается плеером до сетевого upstream, но обычный streaming не засоряет persistent download cache;
- для долгих загрузок используется foreground WorkManager с системным уведомлением;
- Room schema не менялась.

Подробности: `RELEASE_1.6.0.md`.

## Что изменилось в 1.5.0 — Final Vault Polish

- добавлены shared-element переходы постера из локальной и онлайн-медиатеки в единый detail hero; при минимальном motion они автоматически отключаются;
- появился отдельный экран статистики с локальным временем/прогрессом, завершёнными сериями, избранным, 28-дневной активностью и жанровой сводкой по AniList-метаданным;
- плеер получил единый pause-info overlay, а эквалайзер и настройки автопропуска переведены из старых dialog-окон в общие bottom sheets;
- remote provider config теперь принимает endpoint только внутри доверенного host-family конкретного провайдера, что исключает перенаправление токенизированных запросов на произвольный домен;
- AniList OAuth получил одноразовый `state`, который проверяется и удаляется после callback;
- runtime enable/disable источников применяется без перезапуска не только в Source Picker, но и внутри агрегатора «Все источники»;
- `priority` из provider config теперь реально влияет на порядок источников и ранжирование близких по качеству потоков;
- WebView fallback блокирует main-frame переходы на не-HTTPS схемы; file/content access и JavaScript bridge по-прежнему не используются;
- Room schema и backup format не менялись, поэтому миграция базы с 1.4.5 не требуется.

Подробности: `RELEASE_1.5.0.md`.

- нативный онлайн-плеер получил панель серий поверх видео;
- текущая серия подсвечивается, просмотренные отмечаются, для частично просмотренных показывается прогресс;
- список автоматически открывается возле текущей серии;
- выбор другой серии запускает её без возврата на карточку тайтла;
- прогресс текущей серии обновляется в состоянии плеера сразу после checkpoint, поэтому панель не показывает устаревшие данные.

### Надёжность данных

- online history/favourites хранятся в отдельном компактном persistent-store, не смешиваясь с Room-базой локальных файлов;
- открытие тайтла и фактическое воспроизведение фиксируются отдельно;
- завершённая серия автоматически исчезает из «Продолжить», при этом остаётся в истории;
- старый online progress-store остаётся источником позиции воспроизведения, поэтому новая медиатека не ломает существующее возобновление серии.

## Что изменилось в 0.7.5

### Плеер и надёжность

- вертикальный свайп слева регулирует яркость окна, справа — громкость media stream;
- Picture-in-Picture работает для локального и нативного онлайн-видео;
- ручные per-title таймкоды опенинга/эндинга и автоматический пропуск;
- позиция дополнительно сохраняется при уходе приложения в фон;
- при падении нативного онлайн-потока автоматически пробуется следующий вариант с приоритетом той же озвучки;
- `PlayerView` удерживает экран включённым во время воспроизведения.

### Диагностика и единый каталог

- в настройках появился параллельный health-check каталожных источников с задержкой ответа и состоянием токена;
- Jut.su исключён из массового probe, потому что его адаптер работает от URL/slug;
- «Все источники» получил двухминутный in-memory cache с ограничением размера;
- смена токена или сессии инвалидирует кэш объединённого каталога.

### Современный интерфейс

- единая тёмная Material 3 палитра с сдержанными фиолетовыми, бирюзовыми и розовыми акцентами;
- общая система скруглений, границ, отступов и поверхностей для медиатеки, онлайн-каталога, карточек тайтлов и настроек;
- переработанный логотип AnimeVault без старого неонового оформления;
- поиск постоянно доступен и в офлайн-, и в онлайн-библиотеке;
- онлайн-карточки стали крупнее и спокойнее, подписи источников и статусов читаются лучше;
- настройки собраны в единообразные карточки;
- большинство экранов использует семантические цвета MaterialTheme вместо захардкоженного белого текста.

### Офлайн-библиотека

- выбор одной или нескольких корневых папок через Android Storage Access Framework;
- постоянный доступ к выбранным URI, рекурсивное сканирование и необязательное обогащение метаданными MediaStore;
- поддержка MP4, MKV, WEBM, M4V, MOV, AVI, TS, M2TS, 3GP, FLV и прочих `video/*` файлов;
- распознавание `S01E05`, `1x05`, `E05`, `05 серия`, сценовых имён, ревизий эпизодов и диапазонов;
- исправлено распознавание русских слов `серия`, `эпизод`, `сезон`, `часть`: регулярные выражения теперь корректно работают с Unicode-границами слов;
- сезоны могут формироваться как отдельные карточки;
- локальные обложки и ручная замена постера;
- ручная перегруппировка: объединить, отделить, вернуть автоматическую группировку;
- Room хранит папки, тайтлы, серии, субтитры, прогресс, правила группировки и связи с онлайн-релизами;
- ежедневное фоновое пересканирование через WorkManager можно отключить в настройках.

Выбор папки теперь действительно SAF-first: после `OpenDocumentTree` приложение не просит дополнительное глобальное разрешение на все видео. Доступ MediaStore вынесен в настройки как необязательное улучшение системных метаданных.

### Плеер

- Media3 ExoPlayer для локальных файлов и нативных HLS/MP4 потоков;
- встроенные и внешние субтитры `srt`, `ass`, `ssa`, `vtt`;
- точная шкала, кнопки -10/+15 секунд, двойной тап и горизонтальный свайп для перемотки;
- скорость воспроизведения хранится отдельно для каждого тайтла;
- выбранные озвучка и качество онлайн-потока теперь также запоминаются на уровне тайтла и автоматически поднимаются в начало списка в следующей серии;
- эквалайзер с профилями и ручными полосами, если Android предоставляет аудиоэффект;
- восстановление позиции, завершённость серии и автоматический переход к следующей;
- WebView fallback для источников, у которых доступен только встроенный плеер;
- прямое разрешение Kodik в HLS там, где это возможно.

### Онлайн-каталог

В 0.7.5 подключено **11 прямых адаптеров** и виртуальный источник **«Все источники»**:

| Источник | Каталог / поиск | Озвучки / варианты | Воспроизведение |
|---|---|---|---|
| AniLiberty | каталог + поиск | собственный релиз | HLS |
| Kodik | каталог + поиск | много | HLS + embed fallback |
| AnimeLib | каталог + поиск | зависит от релиза | нативно, если доступно + embed |
| AnimeVost | каталог + поиск | собственный релиз | MP4 |
| Jut.su | URL/slug | зависит от страницы | MP4 |
| Dream Cast | поиск | Dream Cast | HLS |
| AniMedia | поиск | AniMedia | HLS |
| AnimeON | поиск | несколько | API stream URL |
| SameBand | новинки + поиск | SameBand | HLS 480/720/1080p |
| AnimeBest | поиск | несколько | iframe -> HLS |
| YummyAnime | каталог + поиск | много плееров и озвучек | Kodik HLS или embed |
| Все источники | объединённый | объединённый | делегирование исходному адаптеру |

«Все источники» группирует вероятно одинаковые тайтлы, объединяет серии и сохраняет происхождение каждого потока, озвучку и физический источник. Приоритет отдаётся внешним ID, затем используются эвристики названия, сезона и года.

### YummyAnime / Yani

YummyAnime добавлен как экспериментальный источник. AnimeVault не содержит чужой application token. Пользовательский `X-Application` token задаётся в **Настройки -> Онлайн-источники -> YummyAnime** и хранится через существующее защищённое хранилище Android Keystore.

Адаптер получает каталог, сведения о тайтле и список видеовариантов, не смешивая понятия «озвучка» и «плеер». Kodik-варианты передаются существующему HLS-резолверу; неизвестные плееры остаются доступными через embed fallback.

Доступность любого онлайн-источника зависит от региона, аккаунта, текущего API и разметки сайта. Ошибка одного адаптера не должна отключать остальные.

## Надёжность 0.7.5

- исправлено проглатывание `CancellationException` сетевыми и ViewModel-операциями: отменённая корутина больше не превращается в ложную ошибку или устаревший результат;
- закрыты гонки при быстрой пагинации онлайн-каталога и смене поискового запроса;
- обновлены R8/ProGuard правила для Gson DTO всех источников, включая envelope-модели, чтобы release-minify не ломал JSON-поля;
- пакет и классы старого `AniLibriaRepository`, который фактически работал с AniLiberty, переименованы в `aniliberty` / `AniLibertyProvider`;
- User-Agent формируется из `BuildConfig.VERSION_NAME`, а не из захардкоженной версии.

## Связь офлайн-тайтла с онлайн-релизом

Откройте локальный тайтл и выберите **«Связать с онлайн»**. Имя локального тайтла используется как исходный запрос. Связь хранит provider ID, ID релиза, постер и внешние идентификаторы, если источник их отдаёт. Локальные видеофайлы при этом не изменяются.

## Сборка

Откройте корень проекта в актуальном Android Studio и установите Android SDK 37, если IDE его запросит.

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest
```

Gradle wrapper настроен на 9.5.0. Для обновления уже установленного APK без потери данных требуется тот же signing key, что и в предыдущей сборке. См. [docs/SIGNING.md](docs/SIGNING.md).

## Структура проекта

- `data/scanner` - SAF/MediaStore-сканирование и разбор имён серий;
- `data/db` - Room entities, DAO и явные миграции;
- `data/repository` - синхронизация локальной библиотеки;
- `data/online` - общий контракт источников, объединённый каталог, HTTP/session helpers;
- `data/metadata` - внешнее обогащение метаданных тайтла (OP/ED, MAL/Shikimori mapping);
- `data/<provider>` - адаптеры конкретных источников;
- `ui/library`, `ui/title`, `ui/online`, `ui/player`, `ui/settings` - Compose UI;
- `ui/components`, `ui/theme` - общая дизайн-система;
- `docs` - release notes, матрица источников, roadmap и технические заметки.

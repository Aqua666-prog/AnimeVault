# AnimeVault 3.0.7 (67)

Подготовка от `main` (`2c81009`), ветка `release/3.0.7`.
Предыдущий тег — `v3.0.6`; исходники до изменения — 3.0.6 (66).

## В выпуске

- Утверждённая айдентика Макимы: launcher/adaptive/round icons, системная
  заставка, приветствие, шапки и раздел «О приложении».
- Makima Entrance: около 1,75 секунды, пропуск при уменьшении анимации,
  сохранённый учёт deep links, восстановления Activity и повторного входа.

Эти изменения уже объединены в main через PR #14. Этот PR меняет только
версию на **3.0.7 (67)** и документацию выпуска.

## Совместимость

Android 7.0+ (API 24+), applicationId `com.sergey.animevault` сохранены.
Room schema 8 и backup format 4 не меняются; новая миграция не требуется.
Источники, воспроизведение, загрузки, авторизация, механизм обновлений,
зависимости и конфигурация подписи не изменены. Существующий ключ сохраняется.

## Проверки

- 13/13 Python-тестов проверки версии релиза и 7/7 тестов генерации JSON прошли.
  Тесты используют фиктивные данные, а не собранный APK.
- Новый CLI подтвердил соответствие исходников `3.0.7 (67)` тегу `v3.0.7`.
- Дополнительно: реальные исходники + фиктивные данные 3.0.7 (67) проходят
  совместную проверку; старый тег v3.0.6 и versionCode 66 в JSON отклоняются.
- `verify-makima-branding.py`: хеши 19 файлов, целостность 17 PNG, 16 XML
  и ссылки ресурсов — успешно.
- `bash tools/verify-final.sh` и `git diff --check` — успешно.
- Сравнение с main: в build-конфигурации изменены только versionName/versionCode;
  функциональные исходники, workflows, схема БД, формат backup и подпись прежние.

Gradle, Android SDK, эмуляторы, сборка APK/AAB, Android unit-тесты и lint
в Codex не запускались. Установка, подпись нового APK и smoke на устройстве
не проверены. Статус: **READY WITH RISKS** — исходники подготовлены;
готовность APK требует GitHub Actions и проверки на устройстве.

## Сборка и публикация

После слияния использовать существующий GitHub Actions workflow
`Build AnimeVault APK`. Для релизного запуска целевой тег — **v3.0.7**;
его код должен содержать версию 3.0.7 (67). При ручном запуске на актуальном
main указать `release_tag = v3.0.7`.

Артефакт: `AnimeVault-debug-<SHA коммита>`, внутри `AnimeVault.apk` и
`animevault-update.json`. JSON автоматически создаётся из того же APK;
обязательная проверка сопоставляет APK, JSON, исходники и тег перед загрузкой.
Не переносить JSON от 3.0.6 и не редактировать его версию вручную.

Тег и GitHub Release этой подготовкой не создаются, workflow вручную не
запускается. APK этой версии в Codex не собирался.

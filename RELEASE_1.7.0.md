# AnimeVault 1.7.0 — Adaptive Home & True Fullscreen

## Пользовательские изменения

- Главная стала устойчивой к узким экранам, landscape и увеличенному системному шрифту.
- Быстрые действия автоматически перестраиваются из одной строки в сетку 2×2.
- Появилось действие «Мне повезёт»: оно выбирает случайный тайтл из всей локальной медиатеки.
- Статистика на главной показывает время просмотра, завершённость коллекции, общий объём и объём просмотренных файлов, который можно освободить.
- Нижняя навигация показывает подпись активного раздела и сохраняет доступные названия для TalkBack.
- На устройствах шириной от 600dp используется navigation rail.
- Отдельный онлайн/загруженный плеер теперь уважает выбранную тему и акцент приложения.

## Исправления

- Устранено двойное применение safe-area insets в корневом `Scaffold` и вложенных экранах; уже применённый shell padding явно consumed.
- Локальный плеер больше не получает системный padding от navigation shell.
- Локальный плеер включает immersive mode независимо от системного автоповорота и возвращает системные панели при выходе.
- Hero главной скрывает дублирующую миниатюру на очень узком экране, сохраняя фоновую poster aura и весь управляющий контент.
- Счётчики прогресса больше не переполняют строку при крупных числах или увеличенном шрифте.

## Совместимость

- `versionCode`: 43.
- `versionName`: 1.7.0.
- Минимальная версия Android: 7.0 (API 24).
- Room schema остаётся версией 5; миграция базы не требуется.
- Формат резервной копии, SAF-разрешения, загрузки, источники и ключи пользовательских настроек не изменены.

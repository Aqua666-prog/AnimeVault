# AnimeVault 1.2.0 — Unified Online Provider Architecture

## Что изменилось

- Онлайн-адаптеры получили явный контракт возможностей (`ProviderCapabilities`).
- Единый каталог больше не угадывает возможности источника по его ID.
- Для пустого каталога используются только источники с browse-поддержкой.
- Для общего текстового поиска используются только источники с обычным текстовым поиском.
- URL/slug-источники не загрязняют глобальный поиск.
- Детали релиза и разрешение потоков проверяют capability-контракт до сетевого запроса.
- Дедупликация сначала использует AniList/MAL/Shikimori ID, затем консервативный title matcher.
- Явно конфликтующие внешние ID больше не могут быть склеены только из-за одинакового названия.
- Диагностика источников показывает не только здоровье, но и поддерживаемые функции.

## Зачем это нужно

Источники теперь являются сменными адаптерами одного ядра. Каталог, поиск и плеер работают с едиными моделями AnimeVault, а особенности конкретного сайта остаются внутри provider-слоя.

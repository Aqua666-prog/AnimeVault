# AnimeVault 1.3.0

Три следующих слоя после единой архитектуры онлайна.

## Автоматическое распознавание локальных файлов

- сканер лучше понимает типичный anime-release формат `Title 07 [1080p]`;
- после SAF-сканирования AnimeVault может автоматически запросить AniList для ещё не размеченных локальных тайтлов;
- автопривязка консервативная: точное нормализованное название, высокий score, совместимое число серий и заметный отрыв от второго кандидата;
- неоднозначные результаты, ремейки и конфликтующие сезоны не применяются автоматически;
- в результате сканирования показывается число автоматически распознанных тайтлов;
- за один scan ограничено число автоматических lookup, чтобы библиотека не превращала перескан в сетевой crawler.

## Продвинутая система источников

- runtime circuit breaker после серии ошибок;
- временный cooldown для нестабильного provider вместо повторных бесполезных запросов;
- ручная диагностика источника обходит cooldown, поэтому пользователь может немедленно перепроверить восстановившийся сервис;
- успешный запрос закрывает circuit breaker;
- единый provider ранжирует потоки по совокупности здоровья, native playback и качества;
- HLS/MP4 получают преимущество над embed при близком здоровье;
- в настройках отображается временная пауза источника.

## Звук и эквалайзер

- существующий per-title Equalizer расширен системными audio effects текущего ExoPlayer audioSessionId;
- LoudnessEnhancer для умеренного усиления тихой дорожки;
- BassBoost с отдельной регулируемой силой;
- пресеты теперь задают не только полосы EQ, но и связанный audio tuning;
- Dialogue: акцент речи + умеренный loudness;
- Bass: низкочастотный EQ + BassBoost;
- Night: усиление разборчивости и громкости без тяжёлого баса;
- ручные loudness/bass sliders сохраняются для тайтла;
- эффекты освобождаются вместе с player audio session и не меняют системный звук телефона.

## Совместимость

- database schema не менялась;
- порог завершения серии остаётся 92%;
- прежняя логика touch-controls не затрагивается;
- OnlineProvider 1.2 contract сохраняется.

# Приёмка дизайн-решения

- Для каждого экрана указаны цель, главный CTA, вторичные действия, состояния и recovery.
- Есть карта использования существующих компонентов и обоснование каждого нового варианта.
- Проверены Vault Lemon Purple, Midnight, AMOLED, Dynamic и fallback на API 24–30; не выданы требования за проверенные работающие темы.
- Размеры проверены для 320/360dp, 600dp и 840dp+ доступной ширины; landscape не обрезает CTA. Fold hinge не пересекает основное действие.
- Font scale 1.0/1.3/2.0, длинные русские названия и многострочные кнопки не перекрывают контент.
- TalkBack: понятный порядок, заголовки, роль/выбор вкладок, доступные альтернативы жестам; фокус не сбрасывается при обновлении списка.
- Загрузка: процент/статус доступны семантически; объявления не идут на каждый байт. Ошибка содержит действие повтора.
- Плеер: кнопки озвучены; seek имеет доступные действия; субтитры не перекрыты; ошибки и buffering читаемы; системные панели и вырезы учтены.
- Motion FULL/REDUCED/OFF и системный animation scale 0: нет скрытого контента, бесконечного shimmer или обязательного parallax при reduced/off.
- Контраст проверяется для текста поверх artwork и всех интерактивных состояний. На низком контрасте используется стабильный scrim/подложка.
- Blur имеет fallback; прозрачность и тени не являются единственным способом различить карточки в AMOLED.
- Превью/макеты отделены от проверок на устройстве. Здесь выполнен только статический анализ, не TalkBack, не performance и не runtime QA.

При реализации в будущем: Compose Preview по размерам/темам, затем ручная проверка TalkBack и устройства API 24 и 31+; тесты поведения только по изменённым сценариям. Эта настройка среды не разрешает сборку или изменение кода.
